Bioinformatics Analysis and Visualisation Platform

An open-source bioinformatics platform under development, designed to make advanced biological data analysis accessible to researchers, students and educators without extensive programming knowledge.

Planned Features
- RNA-seq data analysis
- Volcano plots and heatmaps
- PCA visualisation
- Differential gene expression analysis
- Pathway enrichment analysis
- Publication-quality scientific figures

Research Applications
The platform aims to support research in virology, immunology, molecular biology and cellular metabolism.

Educational Applications
The long-term goal is to collaborate with universities to integrate this platform into biomedical science, bioinformatics and life sciences teaching programmes.

Development Status
Early-stage development. Contributions and collaborations are welcome.
